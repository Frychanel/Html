# Bahía Dorada — Crónicas de la Costa (2005)

Juego 3D de mundo abierto **original** con el estilo de los sandbox urbanos de principios de los 2000.
Se juega en el navegador: es un solo HTML con JavaScript (Three.js incluido en `vendor/`) y no hace falta instalar nada.

## Cómo jugar
Abre `index.html` en el navegador o publícalo con GitHub Pages.

| Tecla | Acción |
|---|---|
| WASD / flechas | Moverse / conducir |
| Ratón | Cámara |
| Shift | Correr |
| Espacio | Saltar / freno de mano |
| F o Enter | Entrar o salir del coche (o robarlo) |
| R | Cambiar emisora de radio |
| H | Claxon |
| C | Distancia de cámara |
| M | Mapa |
| P / Esc | Pausa |

En móvil aparece un joystick y botones táctiles.

## Contenido
- Ciudad de 12×12 manzanas generada por procedimiento, con 7 barrios: Centro (rascacielos), El Mercado, Las Lomas, Villa Palmeras, Barrio Mangle, Puerto Viejo y Playa Coral (playa con muelle).
- Ciclo de día y noche: las ventanas y las farolas se encienden de noche.
- Tráfico con IA, peatones, coches aparcados y 6 modelos de coche.
- Sistema de búsqueda de 5 estrellas: la policía persigue, te arresta y las estrellas bajan si te escondes.
- 3 misiones repetibles: *El Paquete* (Tía Lupe), *Vuelta Rápida* (Chispa) y *Calor Policial* (El Profe).
- 25 discos de oro coleccionables, dinero, salud, hospital y comisaría.
- Radio con 3 emisoras de música sintetizada original, más motor, sirena y claxon (WebAudio).
- Minimapa giratorio, mapa grande y partida guardada en el navegador.

Los personajes, la ciudad, la música y los nombres son originales.
