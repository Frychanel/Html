# Créditos de texturas y cielo

Todas las texturas y el cielo HDRI son de [Poly Haven](https://polyhaven.com), publicados con licencia **CC0** (dominio público).
Se han reducido a 512×512 para que el juego cargue rápido. El HDRI se conserva tal cual, a 1k.

| Archivo | Recurso | Autoría |

| asphalt_02_* | Asphalt 02 | Rob Tuytel |
| concrete_pavement_* | Concrete Pavement | Charlotte Baglioni |
| red_brick_03_* | Red Brick 03 | Rob Tuytel |
| painted_plaster_wall_* | Painted Plaster Wall | Amal Kumar |
| leafy_grass_* | Leafy Grass | Charlotte Baglioni |
| coast_sand_01_* | Coast Sand 01 | Rob Tuytel |
| clay_roof_tiles_* | Clay Roof Tiles | Amal Kumar |
| sky.hdr | Kloofendal 48d Partly Cloudy (Pure Sky) | Greg Zaal, Jarod Guest |

Sufijos: `_diff` = color, `_nor` = normales (OpenGL), `_arm` = R oclusión ambiental / G rugosidad / B metal.
